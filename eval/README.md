# Answer key

The answer key is the ground truth for the agent's extraction accuracy (notebook Part 10). No value in it may come
from the agent's output.

## How the key is made (since 2026-11-08)

1. **Pre-fill by a different model.** Claude read only the papers, the review sheets and the rules below, never the
   agent's outputs, and wrote `prefill/answer_key_prefill.csv`. Each row names where its values are (`where`), how they
   are printed (`printed_as`) and whether it needs a closer look (`confidence` = high or check). This file stays frozen.
2. **Blind sample.** I type L07 and L03 myself into `answer_key.csv` before opening the pre-fill. Comparing the two
   shows how far the pre-fill can be trusted.
3. **Check every row.** The other rows go into `answer_key.csv` with the extra columns. I check each one against the
   paper and set `checked` to `ok` or `fixed`. Only checked rows are scored.

## Files

- `answer_key.csv`: the key. It starts with one header row and no values.
- `prefill/answer_key_prefill.csv`: the frozen pre-fill (see above), never edited.
- `data/answer_key/review_sheets.html` (generated by notebook section 3.11, not committed because it contains paper
  text): one sheet per paper of the frozen library v2. It opens offline in any browser. Each sheet has the title, DOI
  and licence, the sentences that state layer thickness, hatch spacing and spot size, how density was measured, the
  machine, and every table with process parameters or density. Other tables and the full Methods text are folded
  away at the bottom of each sheet.

## How to fill it

1. **One row per parameter set with its measured density.** A table with nine samples gives nine rows. If one sample
   has a density from two methods (for example Archimedes and image analysis), write two rows with the same
   `sample_label` and a different `density_method`. As-built and HIP results of the same sample are also two rows.
2. **A paper with parameters but no measured density:** one row with the parameters, `density_pct` blank and
   "no density reported" in `notes`.
3. **Units as in the column names:** W, mm/s, µm, %. Convert when the paper uses other units (0.6 m/s is 600 mm/s,
   0.03 mm is 30 µm) and write the original in `notes`, for example "speed given as 0.6 m/s".
4. **density_pct is relative density in %.** If the paper gives porosity only, enter 100 minus the porosity and write
   "from porosity 0.46 %" in `notes`. If it gives only an absolute density (g/cm³), leave `density_pct` blank and put
   the value in `notes`. For mean ± standard deviation, enter the mean and note the deviation.
5. **Leave unknown cells blank. Never guess.** A value stated once for all samples (for example "30 µm layers" in
   Methods) goes into every row of that paper. A value the paper does not state stays blank, even if it is typical.
6. **Column meanings**
   - `paper_id`: the PMCID shown on the sheet (for example PMC11818529). `doi`: as on the sheet.
   - `source`: where the values are, for example `Table 2`, `Text 3.1`, `Figure 5a`. Prefer tables and text. If a
     value is read off a figure, say so in `notes`.
   - `sample_label`: the paper's own label (S1, HD, A41, low-VED). Blank if there is none.
   - `density_method`: Archimedes, pycnometry, CT, image analysis, or as the paper names it.
   - `condition`: `as-built` or `HIP` (or the heat treatment written out).
   - `primary_or_quoted`: `primary` if the study measured it itself, `quoted` if the paper takes it from other work
     (a review table, a literature summary table, a dataset cited with a reference number).
   - `notes`: anything odd. Units that look wrong, values that do not add up, ranges ("one density for 700 to 800
     mm/s": leave the speed blank and note the range), replicates, conflicts inside the paper.
7. **Which papers:** all sheets L01 to L10, each in full, except L08. Skip D01, the 25CrMo4 distractor. For the
   review (PMC12194911), enter only 316L rows made by PBF-LB (SLM, L-PBF), not DED or EBM, all marked `quoted`.
   - **L08 (PMC7579382): only Table 5**, the closed porosity by helium pycnometry of samples 13, 9, 5, 6, 1 and 2,
     each as-built (`condition` as-built), after HIP_1 and after HIP_2 (`condition` HIP, the HIP step in `notes`): 18
     rows. Take power and speed for each sample from Table 1, and hatch 0.11 mm, spot 70 µm and layer 50 µm from the
     Methods. I chose Table 5 because it is the smallest L08 table (18 rows, against 32 in Table 2 and 64 in Table 4)
     that still has what L08 is in the library for: as-built and HIP results of the same samples. Its HIP rows carry
     only the condition as a label, with the sample number on the row above, which is a realistic layout trap for the
     Reader. The scoring code scores L08 only on records taken from Table 5.
8. **Saving:** keep it a plain CSV with a dot as the decimal separator. In Excel, save as "CSV UTF-8 (comma
   delimited)". Values that contain a comma go in double quotes (Excel does this by itself).

A made-up example row (not from any library paper), only to show the format:

```
paper_id,doi,source,sample_label,power_W,speed_mm_s,hatch_um,layer_um,spot_um,density_pct,density_method,condition,primary_or_quoted,notes

```
